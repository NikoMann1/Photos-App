# Photos-App

Web app for picking the best photos out of a trip's worth of shots and saving
them back to an iPhone's camera roll.

The app lives in [`photo-picker/`](photo-picker/) — see its README for how to
run it and how to test the save-to-Photos flow on a real iPhone.

Current state: **milestone 1** — end-to-end skeleton with placeholder photo
selection, built to prove the save-to-Photos path before the real scoring work.
